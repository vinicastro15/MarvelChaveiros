Projeto Marvel Chaveiros

Como fiz este projeto

Este projeto foi criado com HTML, CSS e JavaScript para montar uma loja de chaveiros com pesquisa por personagem, catálogo dinâmico e cards responsivos.

A parte visual foi feita com CSS para deixar a página bonita e adaptável em diferentes telas, enquanto o JavaScript carrega os produtos a partir de um arquivo JSON e filtra os resultados em tempo real.
